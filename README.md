📊 Sales Performance Dashboard — Excel + VBA
📌 Project Overview
An interactive Sales Performance Dashboard developed using Microsoft Excel and VBA to analyze sales performance across different cities and sales executives.
The dashboard combines Pivot Tables, Pivot Charts, Slicers, KPI metrics, and VBA automation to transform sales data into an interactive business reporting solution.
🎯 Project Objectives
- Analyze sales performance across different cities.
- Compare sales performance of individual sales executives.
- Monitor Total Sales and target achievement.
- Identify performance gaps using Away From Target %.
- Provide an interactive dashboard for business reporting and decision-making.
- Use VBA to enhance dashboard interactivity and automate user interactions.

📊 Dashboard Features
1. Sales Performance Analysis
Analyzes total sales generated by each sales executive and enables performance comparison.
2. City-wise Analysis
Provides interactive filtering for different cities, including:
- Chennai
- Delhi
- Mumbai
- Nagpur
- Patna
- Pune
- Ranchi
- Surat
3. KPI Metrics
The dashboard tracks:
- Total Sales
- Target Hit %
- Away From Target %
4. Interactive Visualizations
The dashboard includes:
- 📊 Bar Chart — Sales executive performance
- 🥧 Pie Chart — Sales distribution
- 📈 Line Chart — Target performance
5. VBA Automation
VBA was used to enhance dashboard interactivity and connect dashboard controls with slicer-based filtering, allowing users to interact with the report dynamically.

💡 Business Insights
The dashboard can help users:
- Identify high-performing sales executives.
- Compare sales performance across cities.
- Track target achievement.
- Identify employees performing below target.
- Monitor sales distribution.
- Support MIS reporting and management decision-making.
